# UI Design Direction

## Current Direction: Fry Lab HQ

The app should use the **Fry Lab HQ** visual language for the existing screens. This direction is intended to make Fry-By feel more visually appealing, pro, analytical, and lightly gamified without adding new pages, changing the data model, or changing current visible wording.

## Visual Language

- Base: dark charcoal/black backgrounds with a warm brown glow.
- Surfaces: rounded elevated cards with warm brown fills, subtle fry-colored strokes, and soft dark shadows.
- Accent: French-fry yellow/orange should be the primary highlight color.
- Scores: use bold, monospaced numeric score presentation and circular score-ring treatments where appropriate.
- Inputs: keep existing controls and labels, but present sliders/toggles inside analytical card-like panels rather than default iOS form chrome.
- Tone: pro analytics first, playful/gamified second; avoid overly childish visuals.

## Product Constraints For This Pass

- No new screens or pages.
- No new features or flows.
- No copy/label/wording changes.
- No data model changes.
- Existing diary-style list remains the primary log browsing experience for now.

## Future Notes

A dedicated analytics page is desired later. When that work begins, use the same Fry Lab HQ direction: dark dashboard surfaces, score telemetry, trend/radar-style visuals, and fry-orange emphasis.
